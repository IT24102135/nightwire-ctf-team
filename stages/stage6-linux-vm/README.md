## OVA Download

**OVA file (Google Drive):** https://drive.google.com/file/d/1MfpVsjP1ntT1iPdLh6zesJe3HsiiMM2C/view?usp=sharing

**File size:** ~3.3 GB

**Import instructions:**
1. Download the OVA file from the link above
2. Open VirtualBox
3. File → Import Appliance
4. Select `nightwire-final.ova`
5. Click Next → Import
6. Once imported, start the VM and login as `svc_backup`

> Google Drive may show a "can't scan for viruses" warning — this is normal for files > 2 GB. Click "Download anyway".
> The OVA file is hosted separately due to GitHub size limits (100 MB per file).
> The VM contains the intentional vulnerabilities for Stage 6 and the baseline snapshot.
